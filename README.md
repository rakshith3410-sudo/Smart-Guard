# SmartGuard 🛡
### Snatch Theft Detection & Auto-Alert System

A wearable IoT device that automatically detects bag snatch theft 
using G-force threshold detection and triggers an immediate alarm 
with Bluetooth alert — zero manual input required.

## Hardware Used
- Arduino Uno
- MPU6050 Accelerometer
- HC-05 Bluetooth Module
- Piezo Buzzer
- Li-ion Battery

## Features
- Automatic snatch detection (no button press needed)
- Loud buzzer alarm triggers instantly
- Bluetooth alert to phone via Serial Bluetooth Terminal
- Bag left behind detection via Bluetooth proximity
- Total cost under Rs. 2200
